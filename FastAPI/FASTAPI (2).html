FastAPI Guide: Building APIs Made Simple

FastAPI is a fast and easy-to-use Python framework for building APIs. This interactive guide is designed for beginners, with clear examples and clickable sections to make learning fun and engaging. Click the headings below to explore!

📘 1. Python Foundations

Python Syntax & Functions

Python uses indentation (spaces) to organize code instead of braces like other languages. Functions are reusable blocks of code defined with def. Here's a simple function:

def greet(name):
    return f"Hello, {name}!"

Call it with greet("Alice") to get "Hello, Alice!". Python is case-sensitive, and colons (:) start code blocks.

  • Variables: No need to declare types, e.g., name = "Alice".
  • Imports: Use import module to bring in code from other files.

Async/Await

Python's async and await let you write code that doesn't wait idly for slow tasks (like fetching data from a server). Think of it like ordering food and doing something else while you wait:

import asyncio

async def fetch_data():
    print("Start fetching")
    await asyncio.sleep(1)  # Simulate waiting for data
    print("Done fetching")
    return {"data": 123}

async def main():
    result = await fetch_data()
    print(result)

asyncio.run(main())

Use async def for functions that can pause, and await for tasks that take time.

Concurrency (asyncio, coroutines)

Concurrency means handling multiple tasks at once without waiting for one to finish. Imagine juggling tasks while waiting for your coffee. Python's asyncio library uses coroutines (functions that can pause and resume) to achieve this:

  • Coroutines: Defined with async def, they pause at await.
  • Event Loop: asyncio.run() manages all coroutines.
  • Concurrency vs. Parallelism: Concurrency switches between tasks; parallelism runs tasks on multiple CPU cores.

FastAPI uses concurrency to handle many API requests efficiently.

Type Hints (Annotations)

Type hints tell Python what kind of data (e.g., numbers, text) a variable or function should use. They help catch errors and make code clearer:

def sum(a: int, b: int) -> int:
    return a + b

Here, a: int means a should be an integer, and -> int means the function returns an integer. FastAPI uses these for automatic validation.

def surface_area_of_cube(edge_length: float) -> float:
    return edge_length * edge_length * 6

Decorators (Basic Understanding)

A decorator is like a wrapper that adds extra behavior to a function. For example:

def my_decorator(f):
    def wrapper(*args):
        print("Before call")
        result = f(*args)
        print("After call")
        return result
    return wrapper

@my_decorator
def hello():
    print("Hello")

Calling hello() prints "Before call", "Hello", then "After call". FastAPI uses decorators like @app.get("/") to define API routes.

⚙️ 2. Environment Setup

Virtual Environments (venv, pipenv, poetry)

A virtual environment keeps your project's Python packages separate from your computer's main Python setup, avoiding conflicts:

python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

Once activated, pip install only affects this project. Tools like pipenv or poetry make managing dependencies even easier with files like Pipfile or pyproject.toml.

Installing FastAPI and Uvicorn

Install FastAPI and Uvicorn (a server to run FastAPI) in your virtual environment:

pip install fastapi uvicorn

Or use pip install "fastapi[all]" to include extra tools like pydantic-settings.

Project Structure and Folder Organization

Organize your project for clarity. A simple structure looks like:

project/
├── main.py          # Main app file
├── schemas.py       # Pydantic models
├── models.py        # Database models
├── routers/         # API route modules
└── .env             # Environment variables

Keep your API routes in main.py or split them into routers/ for larger projects. Use __init__.py in folders to make them Python packages.

.env Files and Environment Variables

Store sensitive info (like API keys) in a .env file, not in your code. Use Pydantic to load them:

from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    api_key: str
    model_config = SettingsConfigDict(env_file=".env")

settings = Settings()

In your .env file, add API_KEY=your-secret-key. Pydantic loads it into settings.api_key.

🚀 3. FastAPI Basics

Creating FastAPI App Instance

Start by creating a FastAPI app in main.py:

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def read_root():
    return {"message": "Hello World"}

The app = FastAPI() creates your API, and @app.get("/") defines a route at the root URL.

Running App with Uvicorn

Run your app using Uvicorn:

uvicorn main:app --reload

This starts a server at http://127.0.0.1:8000. The --reload flag auto-restarts the server when you change code.

FastAPI Docs (Swagger UI and ReDoc)

FastAPI automatically creates interactive API docs:

  • Swagger UI: Visit /docs to test your API in the browser.
  • ReDoc: Visit /redoc for a cleaner documentation view.

HTTP Methods: GET, POST, PUT, DELETE, PATCH

FastAPI uses HTTP methods to handle different actions:

  • @app.get("/"): Read data (e.g., fetch a list).
  • @app.post("/"): Create data (e.g., add a new item).
  • @app.put("/"): Replace data.
  • @app.delete("/"): Delete data.
  • @app.patch("/"): Update part of the data.

Endpoints

An endpoint is a specific URL (like /items/123) that triggers a function. For example:

@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}

Visiting /items/123 calls read_item with item_id=123.

Path Parameters

Path parameters are parts of the URL in curly braces, like {item_id}. FastAPI passes them to your function:

@app.get("/users/{user_id}")
async def get_user(user_id: int):
    return {"user_id": user_id}

If user_id isn't an integer, FastAPI returns a 422 error.

Query Parameters

Query parameters are extra data in the URL, like /items?q=test. Define them as function arguments:

@app.get("/items/")
async def read_items(q: str | None = None):
    return {"q": q}

If q is required, remove the default value:

@app.get("/items/")
async def read_items(q: str):
    return {"q": q}

Request Body (Pydantic Models)

Use Pydantic models to handle JSON data in requests:

from pydantic import BaseModel

class Item(BaseModel):
    name: str
    price: float

@app.post("/items/")
async def create_item(item: Item):
    return {"item_name": item.name, "item_price": item.price}

Send a JSON like {"name": "Book", "price": 9.99} to this endpoint.

Response Models

Control what data is returned with a response model:

class ItemOut(BaseModel):
    name: str

@app.get("/items/{item_id}", response_model=ItemOut)
async def read_item(item_id: int):
    item = {"name": "Book", "id": item_id}
    return item

This returns only the name field, filtering out others.

Status Codes

FastAPI returns 200 OK by default. Change it with status_code:

from fastapi import status

@app.post("/items/", status_code=status.HTTP_201_CREATED)
async def create_item(item: Item):
    return item

Use status.HTTP_201_CREATED for creation, status.HTTP_404_NOT_FOUND for errors, etc.

Return Types (JSON, dict, list)

FastAPI converts Python objects (dicts, lists, Pydantic models) to JSON:

@app.get("/numbers/")
async def get_numbers():
    return [1, 2, 3]

This returns a JSON array [1, 2, 3].

🔧 4. Intermediate Concepts

Path and Query Parameter Validation

Add rules to parameters, like length or range:

from fastapi import Query, Path

@app.get("/items/{item_id}")
async def read_item(item_id: int = Path(..., gt=0), q: str = Query(None, min_length=3)):
    return {"item_id": item_id, "q": q}

gt=0 ensures item_id is positive; min_length=3 enforces a minimum query length.

Optional Parameters and Defaults

Make parameters optional by setting a default:

@app.get("/items/")
async def read_items(q: str | None = None):
    return {"q": q}

If q isn't provided, it defaults to None.

Form Data

Handle HTML form data (e.g., login forms):

from fastapi import Form

@app.post("/login/")
async def login(username: str = Form(...), password: str = Form(...)):
    return {"username": username}

Install python-multipart to use Form.

File Uploads

Accept file uploads with UploadFile:

from fastapi import File, UploadFile

@app.post("/uploadfile/")
async def create_upload_file(file: UploadFile = File(...)):
    content = await file.read()
    return {"filename": file.filename}

UploadFile handles large files efficiently with metadata like filename.

Headers and Cookies

Access request headers or cookies:

from fastapi import Header, Cookie

@app.get("/items/")
async def read_items(user_agent: str | None = Header(None), session_id: str | None = Cookie(None)):
    return {"user_agent": user_agent, "session_id": session_id}

Custom Response Classes

Return non-JSON responses, like HTML:

from fastapi.responses import HTMLResponse

@app.get("/", response_class=HTMLResponse)
async def get_home():
    return "
Hello, World!
"

Custom Exception Handling

Raise custom errors with HTTPException:

from fastapi import HTTPException

@app.get("/items/{item_id}")
async def read_item(item_id: str):
    if item_id not in fake_db:
        raise HTTPException(status_code=404, detail="Not found")
    return {"item": fake_db[item_id]}

Dependency Injection (Depends)

Reuse code with dependencies:

from fastapi import Depends

async def common_params(q: str | None = None):
    return {"q": q}

@app.get("/items/")
async def read_items(params: dict = Depends(common_params)):
    return params

FastAPI calls common_params and passes its result to the endpoint.

Background Tasks

Run tasks after sending a response:

from fastapi import BackgroundTasks

def write_notification(email: str, message: str):
    with open("log.txt", mode="w") as f:
        f.write(f"notification for {email}: {message}")

@app.post("/send-notification/{email}")
async def send_notification(email: str, background_tasks: BackgroundTasks):
    background_tasks.add_task(write_notification, email, message="Hello")
    return {"message": "Notification sent in the background"}

Middleware

Middleware processes requests before and after your endpoints:

from fastapi import Request
import time

@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    start_time = time.perf_counter()
    response = await call_next(request)
    process_time = time.perf_counter() - start_time
    response.headers["X-Process-Time"] = str(process_time)
    return response

CORS (Cross-Origin Resource Sharing)

Allow web apps on different domains to access your API:

from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

🔗 5. Advanced Backend Features

Database Integration

Connect FastAPI to databases for storing data.

SQL (SQLAlchemy):

from sqlalchemy.orm import Session

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

@app.post("/items/")
def create_item(item: ItemSchema, db: Session = Depends(get_db)):
    db_item = models.Item(**item.dict())
    db.add(db_item)
    db.commit()
    return db_item

NoSQL (MongoDB with Motor):

Use Motor for async MongoDB access, similar to SQLAlchemy but for NoSQL.

CRUD Operations

CRUD stands for Create, Read, Update, Delete:

@app.get("/items/")
def read_items(skip: int = 0, limit: int = 10, db: Session = Depends(get_db)):
    items = db.query(models.Item).offset(skip).limit(limit).all()
    return items

@app.post("/items/")
def create_item(item: ItemCreate, db: Session = Depends(get_db)):
    db_item = models.Item(**item.dict())
    db.add(db_item)
    db.commit()
    return db_item

Async Database Operations

Use async ORMs like Tortoise for non-blocking database calls:

from tortoise.contrib.fastapi import register_tortoise

register_tortoise(app, db_url="sqlite:///db.sqlite3", modules={"models": ["models"]})

@app.get("/users/{user_id}")
async def get_user(user_id: int):
    user = await User.get(id=user_id)
    return user

Pydantic with ORM Models

Combine database models with Pydantic for validation and serialization:

class ItemSchema(BaseModel):
    id: int
    name: str

@app.get("/items/{item_id}", response_model=ItemSchema)
def read_item(item_id: int, db: Session = Depends(get_db)):
    item = db.query(models.Item).filter(models.Item.id == item_id).first()
    return item

Relationships and Joins

Define relationships in SQLAlchemy for linked data:

class User(Base):
    __tablename__ = "users"
    id = Column(Integer, primary_key=True)
    items = relationship("Item", back_populates="owner")

class Item(Base):
    __tablename__ = "items"
    id = Column(Integer, primary_key=True)
    owner_id = Column(Integer, ForeignKey("users.id"))
    owner = relationship("User", back_populates="items")

Pagination and Filtering

Add pagination and search to list endpoints:

@app.get("/items/")
def list_items(skip: int = 0, limit: int = 10, q: str | None = None, db: Session = Depends(get_db)):
    query = db.query(models.Item)
    if q:
        query = query.filter(models.Item.name.contains(q))
    items = query.offset(skip).limit(limit).all()
    return items

🔒 6. User Authentication & Authorization

OAuth2 Password Flow

Secure your API with OAuth2 and tokens:

from fastapi.security import OAuth2PasswordBearer

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

@app.post("/token")
async def login(form_data: OAuth2PasswordRequestForm = Depends()):
    token = create_access_token({"sub": form_data.username})
    return {"access_token": token, "token_type": "bearer"}

@app.get("/users/me")
async def read_users_me(token: str = Depends(oauth2_scheme)):
    user = get_user_from_token(token)
    return user

JWT Tokens (pyjwt)

Use JSON Web Tokens for secure authentication:

import jwt

SECRET_KEY = "your-secret-key"
ALGORITHM = "HS256"

def create_access_token(data: dict):
    return jwt.encode(data, SECRET_KEY, algorithm=ALGORITHM)

def verify_token(token: str):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        return payload
    except:
        raise HTTPException(status_code=401, detail="Invalid token")

Dependency-based Auth

Check user authentication with dependencies:

async def get_current_user(token: str = Depends(oauth2_scheme)):
    credentials = verify_token(token)
    user = get_user(credentials["sub"])
    if not user:
        raise HTTPException(401, "User not found")
    return user

@app.get("/private/")
def private_route(current_user: User = Depends(get_current_user)):
    return {"username": current_user.username}

Role-based Access Control

Restrict access based on user roles:

Check current_user.role in a dependency and raise a 403 error if unauthorized.

Password Hashing (passlib)

Securely store passwords with hashing:

from passlib.context import CryptContext

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def verify_password(plain, hashed):
    return pwd_context.verify(plain, hashed)

def get_password_hash(password):
    return pwd_context.hash(password)

Use .env files and Pydantic for settings, as shown in Environment Setup.

Add logs to track what your app does:

import logging

logger = logging.getLogger("uvicorn.error")

@app.get("/")

from pydantic_settings import BaseSettings

Split code into modules:

Add versions to your API with prefixes:

Error Handling and Custom Exceptions

Handle errors globally:

from fastapi.responses import JSONResponse

@app.exception_handler(SomeCustomError)
async def custom_exception_handler(request, exc):
    return JSONResponse({"message": str(exc)}, status_code=418)

Testing (pytest, httpx, TestClient)

    assert response.status_code == 200
    assert response.json() == {"message": "Hello World"}

🔩 8. FastAPI Utilities

Custom Middleware

Add custom logic to every request:

from fastapi import Request
import time

@app.middleware("http")
async def add_process_time(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)
    response.headers["X-Process-Time"] = str(time.perf_counter() - start)
    return response

Custom Decorators

Create your own decorators:

from fastapi import Header, HTTPException

def require_token(f):
    async def wrapper(*args, token: str = Header(None), **kwargs):
        if token != "expected":
            raise HTTPException(400, "Invalid token")
        return await f(*args, **kwargs)
    return wrapper

@app.get("/secure")
@require_token
async def secure_endpoint():
    return {"secret": "data"}

Response Time Tracking

Track how long requests take (see middleware example above).

Caching (Redis)

Cache data to speed up responses:

import aioredis
import json

redis = aioredis.from_url("redis://localhost")

@app.get("/data")
async def get_data():
    cached = await redis.get("mydata")
    if cached:
        return {"data": json.loads(cached)}
    result = heavy_computation()
    await redis.set("mydata", json.dumps(result))
    return {"data": result}

Throttling / Rate Limiting

Limit requests with slowapi:

from slowapi import Limiter

limiter = Limiter(key_func=get_remote_address)
app.state.limiter = limiter

@app.get("/", limited=True)
@limiter.limit("5/minute")
async def limited_endpoint():
    return {"message": "This endpoint is rate-limited"}

WebSockets

Enable real-time communication:

from fastapi import WebSocket

@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):
    await websocket.accept()
    while True:
        data = await websocket.receive_text()
        await websocket.send_text(f"Message text was: {data}")

🚀 9. Deployment

Uvicorn with Gunicorn

Run FastAPI in production with Gunicorn and Uvicorn workers:

gunicorn -k uvicorn.workers.UvicornWorker main:app

Dockerizing FastAPI App

Create a Docker container:

FROM python:3.9
WORKDIR /code
COPY requirements.txt /code/
RUN pip install --no-cache-dir -r requirements.txt
COPY app /code/app
CMD ["fastapi", "run", "app/main.py", "--port", "80"]

Nginx + FastAPI

Use Nginx as a reverse proxy:

server {
    listen 80;
    server_name example.com;
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

Hosting

Deploy on platforms like Heroku, Render, AWS, or DigitalOcean using Docker or Python setups.

Real-time Notifications (WebSockets / SSE)

Send server updates with Server-Sent Events:

from sse_starlette.sse import EventSourceResponse

@app.get("/stream")
async def message_stream():
